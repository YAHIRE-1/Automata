# 📄🖼️ PDF to JPG Converter (Python)

Convierte archivos PDF en imágenes JPEG de alta calidad usando `pdf2image` y `poppler`.  
Ideal para generar miniaturas, previsualizar documentos o dividir visualmente archivos PDF página por página.

---

## 🚀 Características

- Conversión rápida y sencilla de PDF a JPG
- Soporte para múltiples páginas
- Interfaz gráfica mínima (Tkinter) para seleccionar archivos fácilmente
- Personalización de rutas de entrada y salida

---

## 🧰 Tecnologías utilizadas

- 🐍 Python 3
- 📦 [pdf2image](https://pypi.org/project/pdf2image/)
- 📦 PyPDF2
- 🧊 [icecream](https://pypi.org/project/icecream/) – para debugging ordenado
- 📁 Tkinter – selección de archivos
- 🧠 poppler – requerido por `pdf2image` para hacer la conversión
